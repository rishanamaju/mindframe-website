MINDFRAME WEBSITE — START HERE

FILES INCLUDED
- index.html: website content and page sections
- styles.css: responsive pink/lavender design
- script.js: mobile navigation, reflection prompts, sample blog pop-ups, and demo interest form

PREVIEW ON YOUR IMAC
1. Download and unzip mindframe_website.zip.
2. Open the mindframe_website folder.
3. Double-click index.html to open it in your browser.
4. Keep index.html, styles.css, and script.js together in the same folder.
5. An internet connection loads the Google Fonts; the rest of the site is local.

BEFORE PUBLISHING
This is a front-end prototype. The interest form does not send or save entries. Connect a form backend before collecting real sign-ups. Blog articles are starter articles; there is no private publishing dashboard or database yet. The site does not accept payments. The support button links to the National Brain Tumor Society's official website.

Before publishing, review the wording, add approved contact details and social links, verify fundraising details, and make sure any donation page is official. Avoid publishing private personal information.

CUSTOMIZING
- Edit page text in index.html.
- Edit colors and layout in styles.css.
- Edit reflection prompts and starter blog posts in script.js.

PUBLISHING
You can publish a static site using a hosting service such as Netlify or GitHub Pages. For real sign-ups and blog posts you can publish without editing code, connect a form service and a CMS/database.
